# 📋 Panduan Menjadi Affiliator

**Panduan lengkap untuk menjadi Affiliator, mendapatkan komisi, dan melakukan pencairan dana.**

---

## Quick Start — 5 Menit Jadi Affiliator

1. **Login** ke akun Anda
2. **Buka** menu "Daftar Affiliator" dari profil
3. **Upload** foto KTP dan bukti sosial media
4. **Isi** data rekening bank
5. **Submit** pengajuan → tunggu review admin
6. **Setelah disetujui** → ambil referral link dari dashboard
7. **Share** link ke pelanggan Anda
8. **Pantau** komisi di dashboard
9. **Ajukan** pencairan ketika saldo cukup

---

## A. Apa itu Affiliator?

Affiliator adalah pelanggan yang mempromosikan toko menggunakan **link referral pribadi**. Setiap kali ada orang yang berbelanja melalui link tersebut, affiliator mendapatkan **komisi** dari total belanja customer.

### Bagaimana Cara Kerjanya?

```
Anda mendapat kode referral:
  ABC123

Anda membagikan link:
  https://tokomu.com/?ref=ABC123

Customer klik link → belanja → checkout → order tercatat
→ Anda mendapat komisi sebesar persentase dari subtotal order.
```

### Contoh Perhitungan

| Deskripsi | Nilai |
|---|---|
| Customer belanja (subtotal) | Rp 500.000 |
| Komisi Anda | 5% |
| Komisi yang Anda dapatkan | Rp 25.000 |

Semakin banyak customer berbelanja melalui link Anda, semakin besar komisi yang Anda kumpulkan.

---

## B. Cara Mendaftar Affiliator

### Langkah 1: Login dan Buka Halaman Affiliate

1. Login ke akun Anda
2. Buka halaman **Profil**
3. Klik menu **"Daftar Affiliator"**

### Langkah 2: Isi Formulir Pengajuan

Anda perlu melengkapi data berikut:

#### 📷 Foto KTP (wajib)
- Upload foto KTP yang **jelas dan terbaca**
- Format: JPG, PNG, atau WEBP
- Ukuran maksimal: **5 MB**
- Pastikan seluruh KTP terlihat, tidak blur, dan tidak terpotong

#### 🏦 Data Rekening Bank (wajib)
- **Nama Bank** — contoh: BCA, Mandiri, BRI, BNI
- **Nama Pemilik Rekening** — sesuai nama di rekening bank
- **Nomor Rekening** — 8-20 digit angka (tanpa spasi)

> ℹ️ Data rekening hanya digunakan untuk keperluan pencairan komisi. Nomor rekening tidak akan ditampilkan ke pengguna lain.

#### 📱 Foto Bukti Sosial Media (wajib)
- Upload **screenshot profil atau dashboard** akun sosial media Anda
- Format: JPG, PNG, atau WEBP
- Ukuran maksimal: **5 MB**
- Tujuannya sebagai bukti bahwa Anda memiliki akun sosial media aktif

#### 🌐 Info Sosial Media (opsional)
- **Platform** — contoh: Instagram, TikTok, YouTube, dll
- **Username** — contoh: @namakamu

### Langkah 3: Submit Pengajuan

Klik tombol **"Ajukan Affiliator"** setelah semua data terisi lengkap.

### Apa yang Terjadi Setelah Submit?

Pengajuan Anda akan masuk ke **status PENDING** (Menunggu Review). Admin akan mereview data yang Anda kirimkan, termasuk:

- Kebenaran data KTP
- Kebenaran data rekening bank
- Keaktifan akun sosial media

> ⏱️ Proses review biasanya memakan waktu **1-3 hari kerja**.

### Status yang Mungkin Muncul

| Status | Arti |
|---|---|
| **Menunggu Review** (PENDING) | Pengajuan sedang diproses admin |
| **Disetujui** (APPROVED) | Selamat! Anda sudah menjadi Affiliator |
| **Ditolak** (REJECTED) | Pengajuan ditolak. Lihat alasan penolakan |

---

## C. Jika Pengajuan Ditolak

Jika pengajuan Anda ditolak, Anda akan melihat:

- Status berubah menjadi **"Ditolak"**
- **Alasan penolakan** ditampilkan

### Cara Mengajukan Ulang

1. Buka halaman Affiliator
2. Klik tombol **"Ajukan Ulang"**
3. Perbaiki data yang diperlukan berdasarkan alasan penolakan
4. Upload ulang foto KTP dan/atau bukti sosial media jika diperlukan
5. Submit kembali pengajuan

> ℹ️ Saat submit ulang, data sebelumnya akan di-update (bukan buat baru). Status akan kembali ke **PENDING** untuk direview ulang oleh admin.

---

## D. Setelah Disetujui (APPROVED)

Setelah admin menyetujui pengajuan Anda, Anda akan menerima:

### Kode Referral

Kode unik 6 karakter, contoh: **RAKA7X**, **BUDI92**, **DINA5K**

Kode ini bersifat **permanen** dan tidak bisa diubah.

### Link Referral

Format link referral Anda:

```
https://[domain-toko]/?ref=RAKA7X
```

> Ganti `[domain-toko]` dengan domain website toko tempat Anda mendaftar.

### Cara Mendapatkan Link Referral

1. Buka halaman **Affiliator** dari profil Anda
2. Klik **"Buka Dashboard Affiliator"**
3. Link referral Anda akan ditampilkan di bagian atas dashboard
4. Klik **"Copy Link"** untuk menyalin link

Atau langsung dari halaman status:
1. Kode Affiliator dan Link Referral akan ditampilkan di kartu status
2. Klik tombol **"Copy"** di sebelah link referral

## E. Cara Menggunakan Kode Referral

### Flow Referral Lengkap

```
Anda membagikan link referral
        ↓
Customer mengklik link tersebut
        ↓
Sistem mengenali kode referral Anda
        ↓
Cookie referral tersimpan di browser customer (30 hari)
        ↓
Customer browsing produk di toko
        ↓
Customer melakukan checkout
        ↓
Order tercatat dengan attribusi ke akun Anda
        ↓
AffiliateConversion dibuat
        ↓
Komisi masuk ke dashboard Anda (status: PENDING)
```

### Hal yang Perlu Diketahui

- **Cookie referral berlaku selama 30 hari** — Jika customer mengklik link Anda hari ini, mereka tetap tercatat sebagai referral Anda selama 30 hari ke depan (asalkan tidak mengklik link referral orang lain).
- **Satu customer hanya bisa tercatat ke satu affiliator** — Jika customer mengklik link referral affiliator lain, cookie akan ter-update ke affiliator tersebut.
- **Referral tidak harus langsung checkout** — Customer bisa browse dulu, beberapa hari kemudian baru checkout. Selama masih dalam 30 hari, tetap tercatat.
- **Komisi berdasarkan subtotal order** — Komisi dihitung dari subtotal belanja (sebelum ongkir dan diskon).

## H. Cara Menghitung Komisi

### Dasar Perhitungan

```
Komisi = Subtotal Order × (Commission Rate ÷ 100)
```

**Keterangan:**
- **Subtotal Order** — total belanja customer sebelum ongkos kirim dan diskon voucher
- **Commission Rate** — persentase komisi yang berlaku untuk akun Anda (default: 5%)

### Contoh Perhitungan

| Item | Nilai |
|---|---|
| Subtotal Order | Rp 500.000 |
| Commission Rate | 5% |
| **Komisi Anda** | **Rp 25.000** |

### Hal yang Perlu Diketahui

- **Rate di-snapshot saat order dibuat** — Jika admin mengubah rate Anda setelah order dibuat, komisi order tersebut tetap menggunakan rate lama (saat order dibuat).
- **Komisi dihitung dari subtotal** — Bukan dari total (yang sudah termasuk ongkir dan pajak).
- **Perhitungan menggunakan Decimal** — Sistem menggunakan perhitungan presisi tinggi untuk menghindari kesalahan pembulatan.
- **Rate komisi bisa diubah admin** — Rate Anda bisa berubah sesuai kebijakan admin. Rate maksimal adalah 50%.

## I. Kapan Komisi Masuk?

### Lifecycle Komisi

```
PENDING
  ↓ (admin approve)
APPROVED
  ↓ (admin proses bayar)
PAID
```

### Penjelasan Setiap Status

| Status | Arti |
|---|---|
| **PENDING** | Komisi sedang menunggu. Muncul setelah customer checkout. |
| **APPROVED** | Komisi disetujui oleh admin. Saldo tersedia untuk dicairkan. |
| **PAID** | Komisi sudah dibayarkan ke rekening bank Anda. |
| **CANCELLED** | Komisi dibatalkan. Tidak bisa dikembalikan. |

### Kapan Komisi Dibatalkan?

Komisi akan **otomatis dibatalkan** dalam kondisi berikut:

| Kondisi | Status Komisi |
|---|---|
| Order kedaluwarsa (expired) | PENDING/APPROVED → CANCELLED |
| Pembayaran gagal | PENDING/APPROVED → CANCELLED |
| Order di-refund | PENDING/APPROVED → CANCELLED |
| Admin membatalkan order | PENDING/APPROVED → CANCELLED |

> ⚠️ **Komisi yang sudah PAID tidak akan otomatis dibatalkan.** Jika ada masalah (misal: order perlu direfund setelah komisi dibayarkan), admin akan melakukan review manual.

## J. Cara Withdraw / Pencairan Dana

### Syarat Pencairan

- **Komisi APPROVED** harus tersedia di saldo Anda
- **Saldo tersedia = Total Komisi APPROVED − Total Komisi yang sudah PAID**
- **Maksimal pencairan per request:** Rp 100.000.000
- **Minimum withdrawal:** Tidak ditemukan minimum withdrawal di implementation saat ini (namun jumlah harus lebih dari 0)
- **Hanya 1 request PENDING yang boleh aktif** — Jika Anda sudah memiliki request yang belum diproses, Anda harus menunggu hingga selesai

### Cara Mengajukan Pencairan

1. Buka **Dashboard Affiliator**
2. Pastikan saldo tersedia Anda mencukupi
3. Ajukan pencairan melalui halaman payout
4. Masukkan jumlah yang ingin dicairkan
5. Submit permintaan

### Data yang Digunakan

Sistem akan mengambil data rekening dari data KYC yang Anda submit saat mendaftar:
- Nama bank
- Nama pemilik rekening
- Nomor rekening

> Pastikan data rekening Anda benar saat mendaftar. Perubahan data rekening dilakukan dengan menghubungi admin.

### Status Pencairan

| Status | Arti |
|---|---|
| **PENDING** | Request pencairan sedang menunggu review admin |
| **PROCESSING** | Admin sedang memproses pembayaran |
| **PAID** | Dana sudah ditransfer ke rekening Anda |
| **REJECTED** | Request ditolak admin. Lihat alasan penolakan |
| **CANCELLED** | Request dibatalkan |

### Setelah Request Diterima

1. Admin mereview request Anda
2. Jika disetujui → admin memproses transfer
3. Setelah transfer berhasil → status berubah ke **PAID**
4. Dana masuk ke rekening bank Anda

### Riwayat Pencairan

Anda bisa melihat seluruh history pencairan di dashboard:
- Jumlah pencairan
- Status
- Tanggal request
- Tanggal diproses (jika sudah diproses)
- Alasan penolakan (jika ditolak)

## K. Panel Admin (Untuk Admin)

### Review Pengajuan Affiliate

Admin dapat:
- Melihat daftar semua pengajuan dengan filter status, pencarian, dan sorting
- Melihat detail pengajuan termasuk foto KTP dan bukti sosial media
- **Approve** — menyetujui pengajuan dan generate kode referral
- **Reject** — menolak pengajuan dengan alasan wajib

### Manajemen Affiliate

Admin dapat:
- Melihat daftar semua affiliate
- Filter berdasarkan status
- Pencarian berdasarkan nama/kode
- Sorting berdasarkan berbagai kolom
- Melihat performa: klik, konversi, sales, komisi
- Mengubah **commission rate** (maksimal 50%)
- Mengubah status affiliate (approve, suspend)

### Manajemen Komisi

Admin dapat:
- Melihat daftar semua komisi
- Filter berdasarkan status
- Melihat detail: affiliate info, order info, komisi
- **Approve komisi** — mengubah status dari PENDING ke APPROVED
- **Cancel komisi** — membatalkan komisi (dengan alasan)
- Komisi yang sudah PAID tidak bisa di-cancel otomatis

### Manajemen Payout

Admin dapat:
- Melihat daftar semua request payout
- Melihat data bank affiliate
- **Approve** — menyetujui request payout
- **Reject** — menolak request payout (dengan alasan)
- **Mark Paid** — menandai payout sudah dibayarkan (memerlukan nomor referensi transfer)

### Audit Log

Admin dapat melihat seluruh aktivitas yang tercatat di sistem:
- Affiliate disetujui / ditolak
- Rate diubah
- Komisi diapprove / dibatalkan / dibayarkan
- Payout diapprove / ditolak / dibayarkan
- Order dibatalkan / di-refund
- Komisi auto-cancel (oleh sistem)

Filter berdasarkan jenis aksi dan pagination tersedia.

## M. FAQ (Pertanyaan Umum)

### 📋 Pendaftaran

**Q: Bagaimana cara menjadi affiliator?**
A: Login → buka menu "Daftar Affiliator" dari profil → isi formulir dengan data KTP, rekening bank, dan bukti sosial media → submit → tunggu review admin.

**Q: Berapa lama proses approval?**
A: Biasanya 1-3 hari kerja. Waktu bisa berbeda tergantung volumen pengajuan.

**Q: Apa yang harus diupload untuk bukti sosial media?**
A: Screenshot profil atau dashboard akun sosial media Anda. Bisa dari Instagram, TikTok, YouTube, atau platform lain.

**Q: Apakah bisa submit ulang jika ditolak?**
A: Bisa. Klik "Ajukan Ulang" pada halaman status, perbaiki data yang diperlukan, lalu submit kembali.

---

### 🔗 Referral

**Q: Bagaimana cara mendapatkan kode referral?**
A: Setelah pengajuan disetujui, kode referral otomatis diberikan. Bisa dilihat di halaman status affiliate atau di dashboard.

**Q: Apakah kode referral bisa dipendekkan?**
A: Kode referral sudah berupa kode pendek 6 karakter (contoh: RAKA7X). Tidak bisa diubah atau dipendekkan lagi.

**Q: Bagaimana customer menggunakan referral?**
A: Customer cukup mengklik link referral Anda (contoh: `https://tokomu.com/?ref=RAKA7X`). Sistem akan otomatis mencatat referral.

**Q: Apakah customer harus langsung checkout setelah klik link?**
A: Tidak harus. Cookie referral berlaku selama **30 hari**. Customer bisa browse dulu dan checkout kapan saja dalam periode tersebut.

**Q: Apa yang terjadi jika customer mengklik link referral orang lain?**
A: Cookie akan ter-update ke affiliator yang baru. Artinya, komisi akan masuk ke affiliator yang link-nya terakhir diklik customer.

---

### 💰 Komisi

**Q: Berapa persen komisinya?**
A: Default 5% dari subtotal order. Rate bisa berbeda untuk setiap affiliator (ditentukan admin).

**Q: Komisi dihitung dari total belanja atau subtotal?**
A: Dari **subtotal** (sebelum ongkos kirim, pajak, dan diskon voucher).

**Q: Kenapa komisi saya CANCELLED?**
A: Komisi otomatis dibatalkan jika:
- Order dibatalkan
- Pembayaran expired/gagal
- Order di-refund

**Q: Apakah komisi yang sudah PAID bisa dibatalkan?**
A: Tidak otomatis. Jika ada masalah (misal: refund setelah komisi dibayarkan), admin akan melakukan review manual.

**Q: Kapan komisi bisa dicairkan?**
A: Komisi dengan status **APPROVED** sudah tersedia untuk dicairkan. Komisi **PENDING** belum bisa dicairkan karena masih menunggu validasi.

---

### 💳 Pencairan

**Q: Berapa minimum pencairan?**
A: Tidak ada minimum withdrawal resmi di sistem saat ini. Jumlah harus lebih dari 0 dan tidak melebihi Rp 100.000.000 per request.

**Q: Kenapa payout saya ditolak?**
A: Biasanya karena data tidak lengkap atau tidak sesuai. Lihat alasan penolakan di halaman riwayat payout. Anda bisa mengajukan ulang setelah perbaikan.

**Q: Apakah bisa request payout lebih dari satu sekaligus?**
A: Tidak. Sistem hanya mengizinkan **satu request PENDING** dalam satu waktu. Anda harus menunggu request sebelumnya selesai (di-approve/reject/paid) sebelum mengajukan yang baru.

**Q: Berapa lama proses payout?**
A: Tergantung proses admin. Setelah admin approve dan memproses transfer, status akan berubah ke PAID.

---

### 🔒 Keamanan & Privasi

**Q: Apakah customer lain bisa melihat KTP saya?**
A: Tidak. KTP hanya bisa dilihat oleh admin untuk keperluan review. Customer lain tidak memiliki akses ke data KTP.

**Q: Apakah data rekening bank saya aman?**
A: Ya. Data rekening hanya disimpan untuk keperluan pencairan dan tidak ditampilkan ke pengguna lain.

**Q: Apakah affiliator bisa melihat data customer?**
A: Di dashboard, affiliator hanya melihat **nomor order** dan **nama penerima** dari customer yang berbelanja melalui referral. Data lengkap customer tidak ditampilkan.

**Q: Apakah komisi dihitung dari sisi client atau server?**
A: Seluruh perhitungan komisi dilakukan di **server-side**. Tidak ada komisi yang dihitung dari sisi client.

**Q: Bagaimana referral code divalidasi?**
A: Referral code divalidasi oleh server. Hanya kode dari affiliate dengan status **APPROVED** yang akan menghasilkan konversi.

## N. Troubleshooting

### 🔗 Referral Link Tidak Mencatat Klik

**Yang harus dicek:**
1. Pastikan link yang dibagikan dalam format benar: `https://[domain]/?ref=KODE`
2. Pastikan kode referral Anda aktif (status APPROVED)
3. Klik link dari perangkat yang berbeda untuk testing
4. Pastikan browser tidak memblokir cookie

---

### 💰 Komisi Belum Muncul

**Penyebab yang mungkin:**
1. **Order belum selesai** — Komisi baru muncul setelah customer berhasil checkout
2. **Status PENDING** — Komisi dalam status menunggu, belum terlihat di "Disetujui"
3. **Order dibatalkan/expired** — Komisi otomatis dibatalkan
4. **Cookie expired** — Jika customer checkout lebih dari 30 hari setelah klik link

---

### ❌ Komisi Menjadi CANCELLED

**Penyebab yang mungkin:**
1. Order dibatalkan oleh customer atau admin
2. Pembayaran expired (customer tidak menyelesaikan pembayaran)
3. Pembayaran gagal (ditolak payment gateway)
4. Order di-refund oleh customer
5. Admin membatalkan order

---

### 💳 Payout Belum Dibayar

**Yang harus dilakukan:**
1. Cek status payout di riwayat pencairan
2. Jika status **PENDING** — admin sedang mereview, silakan tunggu
3. Jika status **REJECTED** — periksa alasan penolakan, lalu ajukan ulang
4. Jika sudah lebih dari 3 hari kerja dan masih PENDING — hubungi admin

---

### 🚫 Tidak Bisa Submit Affiliate

**Yang harus dicek:**
1. Pastikan sudah login
2. Jika sudah pernah daftar dan status PENDING — tunggu hingga direview
3. Jika sudah APPROVED — tidak perlu submit lagi
4. Jika status SUSPENDED — hubungi admin untuk penjelasan
5. Pastikan semua field wajib terisi (KTP, bukti sosmed, data bank)
6. Pastikan foto tidak melebihi 5 MB

---

### 🖼️ Preview KTP/Sosial Media Tidak Muncul

**Yang harus dilakukan:**
1. Pastikan file berformat JPG, PNG, atau WEBP
2. Pastikan ukuran file tidak melebihi 5 MB
3. Jika muncul error "Gagal upload" — coba upload ulang
4. Jika masih bermasalah, coba gunakan browser lain atau clear cache

## O. Ringkasan Status

### Status Affiliate

```
PENDING  →  APPROVED  →  (aktif sebagai affiliator)
    ↓
REJECTED  →  (bisa submit ulang)
    ↓
SUSPENDED  →  (hubungi admin)
```

### Status Komisi

```
PENDING  →  APPROVED  →  PAID (selesai)
    ↓
CANCELLED (terminal, tidak bisa diubah)
```

### Status Payout

```
PENDING  →  PROCESSING  →  APPROVED  →  PAID (selesai)
    ↓                        ↓
REJECTED (terminal)     CANCELLED (terminal)
```
